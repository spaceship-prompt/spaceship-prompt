# Daml `daml`

!!! important "This section is rendered asynchronously by default"

!!! info
    [**Daml**](https://daml.com/) is a smart contract language for building distributed applications

The `daml` section displays the current version of Daml.

This section is displayed only when the current directory is within a Daml project, meaning:

* Upsearch finds a `daml.yaml` file

## Options

| Variable | Default | Meaning |
| :--- | :--- | :--- |
| `SPACESHIP_DAML_SHOW` | `true` | Show Daml section |
| `SPACESHIP_DAML_ASYNC` | `true` | Render section asynchronously |
| `SPACESHIP_DAML_PREFIX` | `"using "` | Prefix before Daml section |
| `SPACESHIP_DAML_SUFFIX` | `"$SPACESHIP_PROMPT_DEFAULT_SUFFIX"` | Suffix after Daml section |
| `SPACESHIP_DAML_SYMBOL` | `"Λ "` | Character to be shown before Daml version |
| `SPACESHIP_DAML_COLOR` | `"cyan"` | Color of Daml section |
